1. 执行摘要

灵初提出的不是「更大的单一 VLA」，而是 Psi-R2（执行）+ Psi-W0（评估/迁移/飞轮） 的互补架构，用大规模人类操作数据补齐具身智能的数据供给。

图像 + 语言 → 未来视频 + 机器人动作；WAM / VLA 双属性
Psi-W0
世界模型评估器
图像 + 语言 + 动作 → 未来视频；支持反事实与世界内 RL

核心判断

  • 瓶颈在数据而非再堆一层网络：人类数据规模化 + 信噪比治理，比复杂手工对齐更关键。
  • R2 学成功怎么做，W0 学失败会怎样：后者补上策略学习与 RL 必需的反事实能力。
  • 用 AC-WM 替代传统仿真器：做人类动力学 → 机器人动力学迁移，绕开部分 Sim2Real / 可变形体重建难题。
  • 目标是单本体商业落地：优先「人类数据赋能特定机器人」，而非先做跨本体万能模型。

2. 问题背景：真机数据稀缺与人类数据鸿沟

自动驾驶与大语言模型可依赖海量存量数据；具身智能则同时缺「历史公开库」与「商业化自然回流数据」。 人类双手在产线、零售、日常生活中持续产生高灵巧操作，本应是最自然的数据燃料，但长期卡在两点：

  1. Embodiment Gap：人手与机械臂在运动学、动力学、执行器上不一致，直接复用会失真。
  2. 规模与质量不足：网络第一人称视频或小规模开源集，精度与覆盖远不够支撑预训练。

灵初的回应是：建设可规模采集的人类数据管线（含外骨骼手套、触觉等），并训练 Psi-R2 / Psi-W0，把人类经验转成机器人可执行、可评估、可迭代的策略。

定位澄清： 公开材料将 Psi-R2 + Psi-W0 描述为业内首个约 10 万小时量级人类数据预训练 的具身模型套件； 下文以灵初技术博客《From Human Skill to Robotic Mastery》为主依据，数字与表述以公开版本为准。

为何 R2 有视频预测仍不够？

R2 主要在「成功示范」上学习，难以可靠生成失败后果。 而强化学习、策略诊断、人→机动力学纠偏都依赖反事实（「若这样动会怎样」）。 W0 把动作当作生成条件，并混入失败样本，专门补这一能力。

4. 模型架构细节（Psi-R2 / Psi-W0）

公开材料未给出完整层数/注意力配置的论文级蓝图；可还原的核心是： 共享 Wan2.2 视频生成骨干 + 不同条件注入与输出头。 下列细节综合自灵初技术博客与阿里 Wan2.2 开源说明。

4.1 共享视频骨干：Wan2.2-IT2V-5B-480P

Psi-R2 与 Psi-W0 均以开源视频模型 Wan2.2-IT2V-5B-480P（对应 Wan 系列的 Image/Text→Video 5B 路线；社区常写作 TI2V-5B） 为初始化骨干，再在人类/真机操作数据上继续预训练。

组件 公开可知的作用 备注
文本编码器 UMT5 将语言指令编码为条件向量 Wan2.2 标准组件
3D VAE 把视频编到潜空间；高压缩设计约 T×H×W = 4×16×16（整体压缩约 64） 5B 路线强调部署效率
去噪主干 Dense DiT（Diffusion / Flow Matching Transformer），约 5B 参数 与 Wan2.2-A14B 的双专家 MoE 不同；5B 为 dense
生成范式 在噪声潜变量上迭代去噪 / flow matching，再经 VAE 解码为视频帧 具身任务在此上叠加动作目标
分辨率设定 博客标明 480P 变体 相对 720P 更偏训练/推理成本权衡
注意命名： 灵初写作 Wan2.2-IT2V-5B-480P；阿里官方仓库常写作 Wan2.2-TI2V-5B。 二者均指「文本/图像条件视频生成」的 5B dense 模型族，具体 checkpoint 以灵初内部微调权重为准（未公开）。

4.2 Psi-R2 结构逻辑：视频生成 + 动作联合预测

[图像观测 I_t] ──► 3D VAE / 视觉 token [语言指令 L] ──► UMT5 条件 │ ▼ Wan2.2 DiT（流匹配 / 去噪） │ ├──► 未来视频帧序列 V_{t+1:t+H} （世界建模支路） └──► 机器人动作序列 A_{t:t+H} （策略 / 控制支路） 训练目标（公开表述）：joint prediction of future frames + robot actions 人机对齐：仅做运动学维度映射；图像 raw in；无复杂共享潜空间手工对齐
  • WAM 属性：同一骨干同时「想象未来」与「给出可执行动作」。
  • VLA 属性：对外仍是视觉-语言 → 动作接口，可直接控机。
  • 未公开细节：动作头是独立 MLP/Transformer、与视频 token 共享到哪一层、动作是绝对关节 / 增量 / 末端位姿等，官方博客未给出方程级说明。

4.3 Psi-W0 结构逻辑：动作作为生成条件

[图像观测 I_t] ──► 视觉 token [语言指令 L] ──► 文本条件 [动作轨迹 A] ──► 动作条件（条件注入 / 交叉注意力 / 拼接，具体层未公开） │ ▼ Wan2.2 DiT（同一族骨干） │ └──► 条件于 A 的未来视频 V̂_{t+1:t+H} 与 R2 的关键分叉：动作从「输出」变为「输入条件」→ 可对任意候选动作做反事实推演
  • 训练时额外混入约 30% 失败轨迹，使预测分布覆盖失败后果。
  • 触觉采用 Mask Training：真机无触觉时掩蔽触觉通道；触觉可作为预测标签而非观测。
  • 推理侧不直接输出控制指令，而是给 R2 / RL 提供「世界内 rollout」。

4.5 与前序「快慢脑 / 层级」产品线的关系

灵初早期公开材料（如 Psi-R1）强调 S1 快脑执行 + S2 慢脑推理、Action Tokenizer 闭环等 层级 VLA 叙事；Psi-R2 / Psi-W0 则转向 视频生成式 WAM + AC-WM 双模型。二者同属公司技术演进， 但不应把 R1 的快慢脑结构直接等同于 R2/W0 的内部实现——公开文档未声明 R2 内部仍拆 S1/S2。

5. Psi-R2：策略 / 世界行动模型

5.1 定义与 I/O

Psi-R2 基于预训练视频生成模型构建：输入当前视觉与自然语言指令， 联合预测未来视频帧与机器人控制动作。

  • 从「预测未来世界 + 输出动作」看，属于 World Action Model（WAM）。
  • 从「视觉-语言 → 动作」看，也具备 VLA 形态。
  • 二者不冲突：视频生成骨干同时承担世界建模与动作头。

5.2 骨干与训练目标

  • 骨干：开源 Wan2.2-IT2V-5B-480P
  • 目标：未来视频帧 + 机器人动作联合预测
  • 预训练混合：真机 Psi-MobiDex（~5417 h）+ 人类数据（~95472 h）
  • 后训练：可用少于 100 条真机轨迹微调，覆盖手机装配、工业包装、纸盒折叠等长时序精细任务

5.3 人机数据融合：Raw Data In, Raw Data Out

融合方案刻意极简：人类关节经运动学映射对齐机器人维度；图像几乎不预处理，直接作为观测与标签。 研究重点是用人类数据强化单一目标本体，而非先做跨本体通用策略。

团队曾尝试图像修复、关键点辅助损失、人机共享潜空间对齐等，最终更认同 Bitter Lesson： 数据规模足够后，复杂手工模块常成瓶颈。强行抹平人/机分布差异，对 pick-place 等简单任务或有帮助， 却伤害长时序精细操作——因为动力学本就不该被模糊掉。

5.4 性能真正依赖什么

公开论述强调：相对「再改一层结构」，更决定上限的是人类数据全链路治理—— 配比、调度、课程学习、检索与评估。其中评估高度依赖 Psi-W0： 不能验证「是否真学到人类可迁移技能」，就无法闭环迭代。

5.5 工程：把 WAM 推理压到可用

WAM 常见痛点是推理慢。灵初通过 DiT 缓存、Torch Compile、量化等， 将单次推理从约 2.2 s 压到 <100 ms，以支撑流畅操作。

6. Psi-W0：动作条件世界模型

6.1 定义与 I/O

Psi-W0 同样基于 Wan2.2 视频骨干；与 R2 的关键差异是： 动作轨迹作为条件输入，直接调控未来视频生成。 因此定义为 Action-Conditioned World Model（AC-WM）。

字段 说明
输入 图像观测 + 语言指令 + 机器人动作序列
输出 在该动作条件下的未来场景视频
额外数据 在 R2 同类数据上，再混约 30% 失败轨迹（专项采集或日常采集/推理产生）

6.2 两大职能

  1. 策略评估：在人类数据场景中对 R2 轨迹做推演，检验是否真正吸收人类操作知识。
  2. 人类 → 机器人转换（更核心）：运动学重定向后仍有动力学偏差； 传统做法是重建物体进仿真再 RL，成本高且难处理可变形体。 灵初用 AC-WM 替代仿真器：R2 从人类示范推出轨迹 → 送入 W0 rollout → 切换到机器人视觉/动力学模式 → 在世界模型内 RL 微调，使轨迹在机器人约束下可完成任务。
单条人类示范 → Psi-R2 推断动作 → Psi-W0 条件视频推演（机器人域） → 世界内 RL 纠偏动力学 → 得到可执行机器人轨迹 → 过滤优质样本回流训练（飞轮） → 亦可扰动 W0 合成新场景/新数据

6.3 定位边界

W0 不是第二个任务执行策略。它服务评估、优化与人→机数据转化； 因此必须同时见过成功与失败分布，否则无法支撑世界内 RL。

7. 数据体系与信噪比原则

7.1 信噪比优先于「什么设备炫」

历经多轮实验，公开结论是：在该管线中，数据信噪比（SNR）决定人类数据是增益还是伤害； 低 SNR 数据会主动损害训练。

层级 优先级（公开表述）
数据集构成 任务多样性 > 物体多样性 ≫ 场景多样性
感知模态 精准 3D 位姿 ≫ 触觉 ≫ 2D 图像特征（关键点/分割等）

场景多样性最低，因视频预训练骨干已贡献大量跨背景泛化； 操作是 object-centric，「任务类型覆盖」才是预训练质量核心。

7.2 两类人类数据

  • 高精度可回放：轨迹建在机器人空间，处理后可近似等价真机、可回放； 手套在严格条件下采集的数据是代表，有望在后训练阶段替代部分真机数据。
  • 高泛化可扩缩：精度让位于规模，不适合直接后训练，但能快速撑起预训练泛化。

7.3 采集与 3D 轨迹管线（摘要）

  • 第一人称视频：时空融合的人手检测 → MANO 参数与相机系位姿。
  • 相机内外参与深度：DPVO + Any4D；短暂出画用平滑插值（弃用误差较大的 Infiller）。
  • 纯视频恢复可达毫米级误差；外骨骼手套可压到亚毫米，并配合遥操作校准与漂移修正。
  • 质检：自动标注为主，人工终审；W0 的可视化预测参与质量打分。

7.4 为何坚持「人类数据」而非只赌遥操作

商业落地看重作业节拍（takt）与真实 SOP。工人佩戴手套边干活边采数， 成本低且贴合产线；节拍可接近机械臂物理上限，而遥操作常因人在环观测而偏慢。 因此「高质量人类数据 → 世界模型转换 → 机器人可用轨迹」被视为商业化关键能力， 类比早期 Sim2Real：用零样本 Human2Robot 验证人类数据有效性。

7.5 触觉：跨本体接触桥梁

真机触觉贵、不稳、格式不统一；人类侧采集成本可低于真机约一个数量级。 接触信号在人/机之间相对更可迁移。手套集成触觉后，对真机输入采用 掩码训练：屏蔽触觉观测通道，同时把触觉当作可预测标签， 以提升世界模型对接触/碰撞的建模，并增强交互预判。

失败/试错 通常不在内部世界模型做 RL 层级语义 + KI 等 W0 专做反事实与世界内 RL
跨本体目标 强（多机器人 OXE） 强（开放世界叙事） 公开材料更强调单本体落地

若用一句话对比：OpenVLA / π 系列主要回答「如何用统一策略网络吃多样机器人数据」； 灵初双模型更直接回答「如何把海量人类操作变成可评估、可纠偏的机器人策略」。

10. 工程优化与落地启示

对研发的启示

  • 把预算优先投在可规模、高 SNR 的人类数据采集与 3D 轨迹精度，而不是无限叠加手工对齐模块。
  • 策略与世界模型分工：执行模型吃成功分布；世界模型必须见失败。
  • 评估要可度量：没有 W0 类评估器，人类数据「看起来学了」无法证伪。
  • WAM 要上真机，推理延迟必须工程化（缓存 / 编译 / 量化），否则理论能力无法变成节拍。

与本仓库 picktask 的对照（便于落地理解）

  • 本仓库主线是 LeRobot + ACT 的仿真抓杯：小规模脚本/示教数据、绝对关节动作、无世界模型飞轮。
  • 灵初路线是视频骨干 WAM + AC-WM，数据差两个数量级，问题从「单任务模仿」升级到「人类大数据 → 机器人策略」。
  • 若借鉴：可先在仿真建立「策略 + 可学习动态模型/世界模型」的评估闭环，再谈人类数据迁移——而不是直接照搬 5B 视频模型。

11. 结论与开放问题

结论

  1. Psi-R2 是可直接控机的 WAM/VLA 策略，吃成功人类/真机数据，少样本真机可适配精细长时序任务。
  2. Psi-W0 是 AC-WM，用动作条件视频预测做评估、反事实与人→机动力学迁移，并驱动数据飞轮。
  3. 双模型共享 Wan 视频骨干，但输入输出语义与数据配比刻意不同，避免「只会成功不会失败」。
  4. 公开叙事的竞争力来自人类数据规模 × SNR 治理 × 世界模型闭环，而非单独某个 Transformer 变体。

仍开放 / 需谨慎的点

  • 内部实验称：转换人类数据替代真机后训练，简单抓取效果好，高精细装配成功率仍有提升空间。
  • 多数训练数据、手套硬件与完整训练配方未完全开源；复现门槛高。
  • 「纯人类数据零样本 Human2Robot」被定位为必经之路，但仍属持续攻关方向。
  • 榜单与演示成绩（如公开媒体提及的 MolmoSpaces 等）需以官方最新披露为准，本报告不做未经核验的排名断言。
