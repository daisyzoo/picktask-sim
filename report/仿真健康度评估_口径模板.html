仿真健康度评估 · 口径模板

用途：判断仿真是否好用
复用：填入实测值即可沿用

原则：任务成功率衡量的是策略，不是仿真。 仿真好用 = 能稳定区分策略好坏，且（理想情况下）排名与真机一致；不是仿真 SR 越高越好。

权威参考 · SIMPLER

Evaluating Real-World Robot Manipulation
Policies in Simulation · arXiv:2405.05941

主张：仿真评测不必做成全保真数字孪生；只要 策略相对表现与真机相关、排序一致，即可作为可扩展、可复现的真机评测代理。

要解决什么

  • 通才操作策略真机评测贵、慢、难复现
  • 能力越广，评测负担越大
  • 反转常见 sim→real：问「真机训好的策略，能否在仿真里可靠评？」

两大差距

  • 控制差距：同动作在 sim / real 对末端效果不同
  • 视觉差距：画面分布偏移导致策略行为变
  • 不必极致物性建模；刚体任务上粗物性仍可保持相关
缩小差距的方法
CONTROL
System Identification
用少量真机轨迹开环回放，调仿真 PD（刚度/阻尼），使末端轨迹贴近真机。
VISION · 推荐默认
Visual Matching
绿幕：仿真前景叠真机背景；纹理匹配：真机物体/臂外观贴到仿真资产。优于大幅随机再平均（Variant Aggregation）。
如何衡量「仿真评测管线好不好」
主指标
MMRV ↓
Mean Maximum Rank Violation
排错时按真机差距加权
辅指标
Pearson r ↑
sim SR 与 real SR 线性相关
不必强求完美线性
论文量级（VisMatch）
r≈0.92
Google Robot 平均
MMRV≈0.056 · 很强相关

可带走的结论

1. 仿真好用看 排名是否跟真机一致，不是 SR 绝对值。
2. 管线质量用 MMRV + Pearson r 报告。
3. 优先 Visual Matching + SysID，不必先做全数字孪生。
4. 开源套件：Google Robot / WidowX · Gym API
